\section{Conclusión}

Al completar esta guía, el técnico habrá instalado HomePilot con una arquitectura adecuada para el cliente, validado la operación local, preparado integraciones aprobadas y entregado una cuenta administradora funcional.

\subsection{Resultado esperado}
\begin{itemize}[itemsep=0.15cm]
    \item HomePilot disponible y protegido dentro de la red local.
    \item Perfil de instalación documentado y preservado para futuras actualizaciones.
    \item Dispositivos importados al inventario de HomePilot y asignados a estancias.
    \item Integraciones externas conectadas únicamente con autorización del cliente.
    \item Cliente capacitado para utilizar tableros, rutinas, espacios y conversación con su hogar.
\end{itemize}

\begin{tcolorbox}[title=Entrega profesional]
La entrega termina cuando el cliente puede operar su hogar desde HomePilot y el técnico deja documentada la arquitectura, la dirección local, el responsable administrador y el procedimiento de soporte. La configuración técnica permanece bajo custodia de Nezu.
\end{tcolorbox}
