\section{Validación, entrega y operación}

\subsection{Comprobación técnica}
Ejecute el diagnóstico de solo lectura al finalizar la instalación:
\begin{lstlisting}[language=bash]
bash scripts/install-edge-office.sh --status
\end{lstlisting}

La salida debe confirmar los servicios en ejecución, conectividad local, puertos publicados y disponibilidad de Home Assistant cuando el perfil lo use.

\subsection{Lista de validación de entrega}
\begin{itemize}[itemsep=0.15cm]
    \item La interfaz de HomePilot abre desde el navegador de la red local.
    \item La cuenta administradora ingresa correctamente.
    \item El idioma seleccionado se refleja en interfaz, voz y conversación.
    \item Los dispositivos aprobados aparecen en el inventario y en sus estancias.
    \item Luces, cortinas, sensores, cámaras y reproductores responden según el alcance contratado.
    \item Los tableros visibles corresponden a los permisos de cada usuario.
    \item Las rutinas favoritas aparecen en Inicio cuando han sido marcadas como tales.
    \item Se explica al cliente cómo reportar fallas sin compartir contraseñas ni tokens.
\end{itemize}

\subsection{Actualizaciones}
El técnico actualiza la instalación desde el directorio de HomePilot:
\begin{lstlisting}[language=bash]
git pull --ff-only
bash scripts/homepilot-maintenance.sh --deploy --yes
\end{lstlisting}

El comando conserva el perfil de instalación seleccionado. No debe cambiar un cliente de \texttt{bridge\_ha} a \texttt{ha\_companion} durante una actualización sin una evaluación previa.

\subsection{Mantenimiento y espacio}
Cuando el equipo quede sin espacio, el técnico puede solicitar limpieza controlada desde el asistente de instalación o usar las opciones documentadas de mantenimiento. Antes de una limpieza, verificar respaldos y confirmar que no se borrarán volúmenes de datos.

\subsection{Acceso remoto}
El acceso remoto debe habilitarse solo si está contratado. Use un mecanismo autenticado y auditable, por ejemplo Cloudflare Access, VPN o una solución aprobada por Nezu. Nunca exponga la API ni Docker directamente a Internet.
