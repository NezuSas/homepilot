\section{Requisitos previos}

Antes de iniciar, el técnico debe confirmar el alcance comercial y las condiciones mínimas del sitio.

\subsection{Información que se debe recopilar}
\begin{itemize}[itemsep=0.15cm]
    \item Nombre del cliente, dirección y responsable técnico.
    \item Red Wi-Fi o LAN destinada a dispositivos inteligentes.
    \item Inventario de dispositivos, marcas y protocolos: luces, cortinas, cámaras, sensores, audio y pantallas.
    \item Si el cliente ya usa Home Assistant y la URL local por la que es accesible.
    \item Disponibilidad de una cuenta administradora del Home Assistant existente para emitir un token de larga duración.
    \item Preferencia de acceso remoto, si forma parte del alcance contratado.
\end{itemize}

\subsection{Requisitos de hardware}
\begin{table}[h]
\centering
\begin{tabularx}{\textwidth}{|L{0.30\textwidth}|X|}
\hline
\textbf{Componente} & \textbf{Recomendación mínima} \\
\hline
Equipo anfitrión & Mini PC o servidor local siempre encendido, con procesador x64 moderno. \\
Memoria & 8 GB de RAM para HomePilot con voz, cámaras e integraciones. \\
Almacenamiento & 64 GB SSD como mínimo; 128 GB o más si habrá cámaras, modelos de voz o registros extensos. \\
Red & Ethernet recomendado; IP reservada por DHCP o IP estática. \\
Energía & UPS recomendada para el equipo anfitrión, router y switch crítico. \\
\hline
\end{tabularx}
\caption{Requisitos físicos recomendados}
\end{table}

\subsection{Requisitos de software}
\begin{itemize}[itemsep=0.15cm]
    \item Docker Engine y Docker Compose disponibles para el usuario técnico.
    \item Git instalado para recibir actualizaciones controladas.
    \item Navegador moderno en un equipo de administración.
    \item Acceso a Internet únicamente durante instalación, descarga de imágenes y actualizaciones autorizadas.
\end{itemize}

\begin{tcolorbox}[title=Seguridad antes de instalar]
No publique puertos de administración en Internet sin una solución de acceso autenticado. Las contraseñas, tokens de Home Assistant y secretos de integraciones no se anotan en esta guía ni se entregan al cliente por canales inseguros.
\end{tcolorbox}
